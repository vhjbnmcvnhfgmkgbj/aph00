# Jarvis برای اندروید (نسخه‌ی APK)

این پروژه با Kivy نوشته شده و با Buildozer به APK تبدیل می‌شود.
کلید API داخل APK نیست؛ بعد از نصب، از دکمه‌ی SET وارد کنید.

## ساخت APK — روش ۱ (ساده‌ترین، بدون نصب چیزی روی کامپیوتر): GitHub Actions
1. در github.com یک مخزن (repository) خصوصی بسازید.
2. همه‌ی فایل‌های این پوشه (از جمله پوشه‌ی `.github`) را داخلش آپلود کنید.
3. تب **Actions** → ورک‌فلو **Build APK** را اجرا کنید (یا خودکار بعد از push اجرا می‌شود).
4. بعد از حدود ۲۰ تا ۴۵ دقیقه، از پایین صفحه‌ی اجرا، فایل **jarvis-apk** را دانلود کنید؛ داخلش فایل `.apk` است.

## نصب روی گوشی
فایل APK را به گوشی منتقل کنید و باز کنید؛ اگر خواست، «نصب از منابع ناشناس» را اجازه دهید.

## امکانات و محدودیت‌ها
- گفتگو با Gemini یا Anthropic، حافظه‌ی گفتگو، پشتیبانی از فارسی راست‌چین.
- دستورها: «کروم رو باز کن»، «تلگرام رو باز کن»، «google.com رو باز کن»، «پایتون چیه رو سرچ کن»، و دستورهای آزاد (مثلاً «تو یوتیوب آهنگ آرام پیدا کن»).
- **MIC**: پنجره‌ی استاندارد تشخیص گفتار گوگل (فارسی).
- **باز کردن فایل و پوشه** در اندروید پشتیبانی نمی‌شود.
- **صدای فارسی** فقط وقتی کار می‌کند که موتور Text-to-speech گوشی فارسی داشته باشد؛ وگرنه پیام هشدار می‌دهد.
- کیبورد اندروید در Kivy حروف فارسی را هنگام تایپ جدا نشان می‌دهد؛ پیش‌نمایش درست بالای کادر تایپ نمایش داده می‌شود. برای فارسی، MIC راحت‌تر است.
- مجوز `QUERY_ALL_PACKAGES` برای پیدا کردن برنامه‌های نصب‌شده لازم است (برای نصب مستقیم APK مشکلی ندارد، ولی در گوگل‌پلی محدودیت دارد).
